## More details
SpecPort brings interactive API reference docs into Confluence, where your team already writes.

- Supports OpenAPI 3.x and Swagger 2.0, in YAML or JSON
- Three sources: paste, page attachment or public GitHub file
- Paste a GitHub link to an openapi.yaml and it becomes live docs automatically
- Swagger UI viewer with tags, schemas and examples
- Optional Try it out, with calls sent from the reader's browser
- PDF and Word export print a clean endpoint table, not a blank box
- GitHub fetches are cached for 10 minutes to keep pages fast
- Runs on Atlassian's Forge platform, ready for Connect end of support on 31 Jan 2027

Coming soon: private GitHub, GitLab and Bitbucket repos.
