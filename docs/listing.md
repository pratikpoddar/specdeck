# Marketplace listing copy

**App name:** SpecPort: OpenAPI & Swagger Docs for Confluence

**Tagline (≤ 80 chars):** Interactive OpenAPI docs in Confluence. Forge-native, one-click migration.

**Summary:**
Turn any OpenAPI 3 or Swagger 2 spec into interactive API documentation on a Confluence page. Paste it, attach it, or drop in a GitHub link. Moving off a retiring Connect Swagger app? SpecPort converts those macros for you in one click.

## Highlights
1. **Docs from any source.** Paste YAML or JSON, use a page attachment, or paste a GitHub link and it becomes live docs automatically.
2. **Migrate in one click.** A space-settings tool finds Swagger and OpenAPI macros from other apps and converts them, keeping a page version so you can roll back.
3. **Built on Forge.** Runs entirely on Atlassian's platform, with no outside servers and no personal data. Ready for Connect end of support on 31 Jan 2027.

## More details
- Swagger UI viewer with endpoint list, schemas and examples
- Optional "Try it out" for live API calls
- PDF and Word export print a clean endpoint table, not a blank box
- Check spec validates your spec before you save
- Cached GitHub fetches keep pages fast

## Pricing
- Free for up to 10 users, with every feature.
- Paid tiers unlock one-click migration, "Try it out" and (soon) private GitHub, GitLab and Bitbucket repos.
